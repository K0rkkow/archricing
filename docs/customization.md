# Customization — tout est graphique

Ouvrir **ArchRicing Settings** (dock) ou `archricing settings`.

- Appearance : Sakura/Aurora/Ocean/Midnight/Dream/Cyber/Minimal (1 clic = wallpaper+couleurs+terminal+dock).
- Terminal Transparency : slider 0–100% + Blur ON/OFF (Kitty `background_opacity`, KWin `Effect-Blur`).
- Wobbly : OFF/SUBTLE/NORMAL(défaut)/PLAYFUL (natif KWin, GPU).
- Animations : MINIMAL/SMOOTH/AESTHETIC/PLAYFUL (durée, courbes, dock, notifications).
- Dock : taille, opacité, blur, taille/espacement icônes, auto-hide, magnification.
- CLI : `archricing theme|wallpaper|settings|update|info|diagnose|reset`.
- Reset : `archricing reset` (backup `*.bak-*` systématique).
- Jamais de fichier texte obligatoire pour une propriété visuelle simple.

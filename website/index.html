01 // WHAT IS ARCHRICING?

01. WHAT IS ARCHRICING?

An independent Linux distribution project based on Arch Linux. A preconfigured ISO: live desktop, graphical installer, full visual identity, graphical tools, optional security toolkit. ArchRicing is an independent project — not official Arch Linux.

08 // INSTALL

08. FROM ISO TO DESKTOP

DOWNLOAD ISO (no public release yet)
BOOT → ARCHRICING LIVE DESKTOP
CLICK “INSTALL ARCHRICING” → CALAMARES
USER / KEYBOARD / TIMEZONE / DISK (ext4 · Btrfs · LUKS · swap)
EDITION: NORMAL or SECURITY + EXPERIENCE OPTIONS
INSTALL → REBOOT → ARCHRICING DESKTOP

09 // BUILD YOUR OWN ISO

09. ONE COMMAND ENERGY

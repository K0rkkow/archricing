BUILDING Implemented

build.sh is the single entry point. Internals stay internal.

git clone https://github.com/K0rkkow/archricing.git
cd archricing
./build.sh

Needs

  • Arch Linux / Arch-based + pacman (never Windows natively).
  • archiso (offered for auto-install), ~20 GB disk, sudo.

Pipeline

  1. Compat, dependency, file checks.
  2. One sudo prompt, work/ cleanup.
  3. Profile: packages from packages/, airootfs live files, config (profiledef, pacman.conf).
  4. mkarchiso → verified out/archricing-....-x86_64.iso + SHA256SUMS.

Flags: --help · --check-only · --clean. Test: ./tests/test-qemu.sh uefi.

[ NOTE ]Preflight-tested only — mkarchiso never ran. No ISO exists.

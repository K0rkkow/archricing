DESKTOP Implemented

KDE Plasma 6 on Wayland as a classic floating desktop. Partial: configured in files, never seen running.

You get

  • SDDM login, Plasma Wayland session, Dolphin, Firefox, monitor, screenshot, partition manager.
  • Click-to-focus windows with normal minimize/maximize/close buttons.
  • Top-panel network, Bluetooth, sound, battery, notifications — all clickable.
  • Virtual desktops + Overview thumbnails, mouse-driven.

You don't get

  • No auto-tiling, no splits, no imposed zones.
  • No mandatory Super+Q/W/1/2/3 system; Ctrl+C/V/Z/S keep working.
  • No latte-dock (unmaintained): native floating Plasma panel instead.

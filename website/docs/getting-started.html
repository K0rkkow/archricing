GETTING STARTED

What is ArchRicing?

An Arch-based distribution: preconfigured ISO, KDE Plasma on Wayland, Calamares installer, full visual identity, graphical tools, optional security toolkit. Boot → live desktop → Install ArchRicing → same desktop after reboot. Partial: sources complete, no ISO built or booted yet.

What you need

  • Use: x86_64 machine/VM, UEFI preferred, 4 GB RAM. No public ISO yet — see Download.
  • Build: Arch / Arch-based + pacman, ~20 GB free, sudo. Then git clone … && cd archricing && ./build.sh.

From Windows

Never build natively. Use WSL2-Arch or an Arch VM. tests/check-tree.sh runs under Git Bash but validates structure only.

Vocabulary

  • archiso — official tool turning a profile into a bootable ISO (mkarchiso).
  • Calamares — graphical installer from the live desktop.
  • airootfs — live file tree packed into the image.
  • Floating — windows you move/resize with the mouse; nothing tiles itself.

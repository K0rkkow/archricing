TERMINAL Implemented

Kitty (default) & Konsole

Kitty: transparent (background_opacity 0.72), blur behind, pastel colors, padding, Nerd Font ligatures. Wallpaper stays visible — never opaque by default. Opacity slider + blur toggle in Settings. Konsole available; installer picks kitty / konsole / system.

Shells & prompt

Zsh default (classic, no exotic bindings; eza/bat/fzf aliases), Bash one choice away, Starship ArchRicing prompt (toggleable).

DEVELOPMENT Implemented

Environment

Arch + base-devel archiso git shellcheck python. Windows folks: WSL2/VM for builds, Git Bash for static checks.

Rules

  • Idempotent scripts, backup before overwrite.
  • Floating-only, mouse-first, no imposed shortcuts.
  • Real package names (archlinux.org); AUR = confidence + fallback.
  • Security tools never auto-run; never invent packages.

Validate

bash tests/check-tree.sh
bash tests/validate-packages.sh  # on Arch
./build.sh --check-only

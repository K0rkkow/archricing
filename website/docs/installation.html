INSTALLATION Planned

Designed and wired in the repo (Calamares configs + custom module). Never run on hardware.

Flow

  1. Boot ISO → live desktop.
  2. Install ArchRicing → Calamares.
  3. Language, keyboard, timezone.
  4. User, password, machine name.
  5. Edition: 🌸 Normal / 🛡️ Security.
  6. Experience page: theme, dock, effects, terminal, shell, apps.
  7. Disk: auto/manual, ext4/Btrfs, LUKS, swap.
  8. Bootloader → reboot → your desktop.

Saved to /etc/archricing/install-profile.conf for Settings to re-read.

[ DISK ]Auto-partitioning erases the target disk. Back up, double-check the drive, stay plugged in.

First boot

SDDM → Plasma with your choices → Welcome opens once → Fastfetch greets the first terminal → Security edition finishes AUR installs in background (~/.local/share/archricing/security-aur.log).

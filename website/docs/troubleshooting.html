TROUBLESHOOTING

Build fails / archiso missing

Run ./build.sh --check-only: it names the missing piece. On Arch: sudo pacman -S archiso. Check disk space (20 GB) and sudo rights.

Package not found / AUR unavailable

Official: pacman -Si <name> (or tests/validate-packages.sh). AUR: skipped + logged by design; check fallbacks in packages/security/security-aur.txt.

No ISO generated / permission denied

./build.sh never prints success without a real ISO + SHA256SUMS. Re-run with the log; ensure single sudo prompt succeeded and out/ is writable.

KDE / Wayland / black screen / drivers

Unverified territory: try a second TTY, check archricing diagnose when installed. NVIDIA → nvidia-open nvidia-utils egl-wayland. VMs need 3D accel + UEFI firmware.

No network / audio / Bluetooth

Services NetworkManager, pipewire, bluetooth are enabled by install; restart them, check the top-panel applets, then archricing diagnose.

Wobbly / transparency missing

KWin-effect + GPU dependent. Wobbly SUBTLE if blur flickers (#474196). Kitty opacity lives in ~/.config/kitty/kitty.conf (background_opacity).

Asking for help

Include: edition, hardware/GPU, ISO date or commit, archricing diagnose output, exact error text.

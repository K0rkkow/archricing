WINDOWS Implemented

Floating, always

Windows open where they want and stay until you move them. Titlebar drag, edge resize, manual snap, minimize/maximize/close buttons. Tiling and quick-tiling disabled in kwinrc.

Wobbly

Native KWin, GPU: off · subtle · normal (default) · playful.

[ NOTE ]Blur can flicker mid-wobble on Wayland (upstream KWin #474196, partly fixed in 6.4). SUBTLE helps.

Animations & performance

Profiles MINIMAL/SMOOTH/AESTHETIC/PLAYFUL. Performance mode kills wobbly + blur and shortens motion — config kept.
